# 🛒 E-commerce Sales Analytics

### End-to-End Data Analytics Project Using Python, MySQL and Power BI

## 📌 Project Overview

This project focuses on analyzing e-commerce sales data to understand business performance, customer behavior, product performance, and sales trends.

It follows an end-to-end data analytics workflow using Python for data generation and preparation, MySQL for database storage and management, and Power BI for interactive data visualization.

## 🎯 Project Objectives

* Analyze overall e-commerce sales performance.
* Understand customer and order trends.
* Identify top-performing products and categories.
* Track monthly revenue trends.
* Analyze state-wise sales performance.
* Generate meaningful business insights.

## 🛠️ Technologies Used

| Technology       | Purpose                         |
| ---------------- | ------------------------------- |
| Python           | Data generation and preparation |
| Jupyter Notebook | Python development              |
| MySQL            | Database storage and management |
| Power BI         | Data analysis and visualization |

## 📊 Dataset Information

The project contains five datasets representing different aspects of an e-commerce business. 

| Dataset           |     Records |
| ----------------- | ----------: |
| Customers         |      25,000 |
| Products          |       2,000 |
| Categories        |          10 |
| Orders            |     100,000 |
| Order Items       |     300,000 |
| **Total Records** | **427,010** |

**Data Period:** January 2025 – December 202
